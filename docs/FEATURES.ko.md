# 상세 기능 안내

[English](FEATURES.md) · **한국어** · [README로 돌아가기](../README.ko.md)

| 기능 | 설명 |
|---|---|
| **SSH 터미널** | SwiftTerm 기반 터미널. OS SSH 명령을 그대로 실행하거나 내장 libssh2 엔진으로 연결할 수 있습니다. 로그인 배너와 MOTD를 유지하며 현재 작업 디렉터리를 추적합니다. |
| **SSH 연결 설정** | 포트, 비밀번호·개인 키·매번 묻기·SSH 에이전트 인증, 인코딩, 알고리즘, 프록시, 시작 디렉터리와 초기 명령을 설정합니다. OS SSH 모드에서는 기존 SSH 설정과 별칭을 사용할 수 있습니다. |
| **점프 호스트** | ProxyJump로 배스천을 거쳐 연결합니다. 점프 호스트는 기존 SSH 설정·키·에이전트로 인증하며, 대상 서버 설정과 프록시 URL은 호스트 폼에서 관리합니다. |
| **SSH 에이전트** | 시스템 ssh-agent, 1Password, Secretive를 지원합니다. 개인 키는 에이전트에 남아 있으며 앱으로 전달되지 않습니다. 에이전트가 키 사용 승인을 요청할 수 있습니다. |
| **SFTP 파일 관리** | 업로드·다운로드·이름 변경·권한 변경, 동시 전송 큐, 업로드 이어받기와 압축 전송, 원격 파일 편집을 지원합니다. |
| **오른쪽 파일 패널** | SSH 서버 옆에서 원격 파일 트리를 표시합니다. 터미널의 디렉터리 변경을 따라가며, 자동 따라가기와 패널 표시 여부·너비를 조절할 수 있습니다. 파일을 클릭하면 편집기로 엽니다. |
| **파일 목록** | 디렉터리를 정렬해 살펴보고 파일을 선택하거나 여러 파일을 전송합니다. 즐겨찾기, 최근 파일, 다른 앱으로 열기·공유, 파일 정보와 컨텍스트 메뉴를 제공합니다. |
| **원격 코드 편집기** | 구문 강조, 검색·바꾸기, 미니맵, 자동 들여쓰기, 변경 표시, 실행 취소를 지원합니다. 저장 시 외부 변경을 감지하고 덮어쓰기·다시 불러오기를 선택할 수 있습니다. |
| **sudo로 편집** | 권한이 부족하면 sudo로 열기·저장을 선택합니다. 서버별 sudo 비밀번호는 앱 실행 중 메모리에만 보관하며, 명령줄 대신 표준 입력으로 전달합니다. `requiretty`가 필요한 서버에서는 사용할 수 없습니다. |
| **원격 데스크톱** | Windows RDP와 VNC를 지원합니다. VNC 기본 포트는 5900이며, macOS 화면 공유에는 사용자 이름이 필요할 수 있습니다. 자격 증명 저장을 선택하면 로그인에 성공한 뒤 저장합니다. |
| **원격 화면 도구 모음** | 제어·보기 전용, 키 조합 보내기, 스크린샷 복사·저장, 확대·축소·화면 맞춤, 원격 해상도에 창 맞추기, 전체 화면, 연결 해제·재연결을 제공합니다. |
| **포트포워딩** | 서버별 규칙을 한 작업 공간에서 검색·필터링하고 시작·중지합니다. 로컬 `-L`, 원격 `-R`, 동적 SOCKS `-D`, 데이터베이스·웹 포트 프리셋과 고급 주소 설정을 지원합니다. 창을 숨겨도 백그라운드에서 동작합니다. |
| **서버 가져오기·내보내기** | File 메뉴의 Import Servers·Export Servers 또는 호스트의 목록 관리 창에서 실행합니다. SSH·RDP·VNC 설정, 메모, 색상, 빈 섹션을 포함한 그룹을 JSON으로 옮깁니다. 중복은 건너뛰며 비밀번호와 개인 키는 내보내지 않습니다. |
| **호스트 관리** | 서버와 섹션을 추가·편집·정렬하고 색상과 메모를 지정합니다. iTerm2에서 내보낸 SSH 프로필 JSON도 가져올 수 있습니다. |
| **서버별 탭** | 위쪽은 서버, 아래쪽은 해당 서버의 파일·편집기·개요 탭으로 구성됩니다. 터미널은 별도의 하단 패널에 표시하며 높이와 표시 여부를 조절할 수 있습니다. |
| **터미널 도구 모음** | 현재 경로 복사, 해당 경로에 업로드·파일 생성, 파일 브라우저 열기, 스크립트, 포트포워딩, 개요, 화면 지우기, 새 터미널을 제공합니다. 설정에서 숨길 수 있습니다. |
| **호스트 개요** | 연결 상태·응답 시간·시스템 사양, 경고, 실시간 사용량, 빠른 작업, 즐겨찾기, 최근 파일, 등록한 로그와 메모를 모아서 표시합니다. |
| **실시간 모니터링** | CPU·메모리·디스크·네트워크·GPU·가동 시간을 표시합니다. Linux는 `/proc` 등을 읽으며 지원 여부에 따라 항목이 달라집니다. 지속적인 부하에는 시스템 알림을 보낼 수 있습니다. |
| **호스트 경고** | 지원되는 시스템에서 디스크 부족, 비밀번호·계정 만료, 재부팅 필요 상태를 표시합니다. 읽기 전용·가상 파일시스템은 디스크 부족 경고에서 제외합니다. |
| **연결 상태·응답 시간** | TCP와 SSH 응답으로 온라인 상태와 지연을 확인합니다. 별도의 Ping 목록에서 서버 상태를 모아 볼 수 있습니다. |
| **로그·저장 공간** | 서버별 로그를 등록해 실시간으로 따라가고, 폴더·디스크 사용량을 분석합니다. 즐겨찾기와 최근 파일에서 자주 쓰는 경로로 이동할 수 있습니다. |
| **SSH 키 라이브러리** | ed25519·RSA 키를 생성·가져오고 연결에 사용합니다. 개인 키는 Keychain에 보관합니다. |
| **SSH Key Manager** | 실제 `~/.ssh` 또는 선택한 디렉터리의 키 파일을 관리하는 별도 도구입니다. 생성·복사·이름 변경·삭제·주석·암호 변경, `config`의 Host 블록 편집과 연결 확인, `known_hosts` 조회·삭제를 지원합니다. 읽기 전용 모드를 제공합니다. |
| **AI 프로필·채팅** | 서버별 AI 프로필과 대화를 보관하고 모델을 선택합니다. 제안 명령을 터미널로 보내거나, CLI를 이 Mac 또는 서버에서 실행합니다. 경로 선택기로 작업 위치를 지정할 수 있습니다. App Store 버전은 서버 실행 모드를 사용합니다. |
| **AI 실행 권한** | Mac에서 실행하는 AI CLI는 로그인 계정 권한으로 서버 명령을 직접 실행할 수 있습니다. 채팅에 제안된 명령은 Run in Terminal을 눌렀을 때 실행됩니다. CLI 설치·로그인은 실제 실행 위치에서 해야 합니다. |
| **스크립트** | 자주 쓰는 명령을 그룹으로 보관하고, 변수를 채운 뒤 실행하거나 명령줄에 삽입합니다. 여러 서버에서 명령을 실행하고 실행 기록을 확인할 수 있습니다. |
| **Docker·Podman** | 지원되는 서버의 컨테이너와 이미지를 관리하고 관련 상태를 확인합니다. 웹 서비스는 SSH 터널을 통해 열 수 있습니다. |
| **서버 운영 도구** | systemd 서비스, 열린 포트, 프로세스, 방화벽 규칙, 보안 요약과 확장 모니터링을 제공합니다. 원격 시스템과 설치된 도구에 따라 사용할 수 있는 기능이 다릅니다. |
| **네트워크 도구** | HTTP Check와 여러 네트워크 진단 도구를 제공합니다. Wake-on-LAN, 재부팅·종료, tmux·zellij 세션 접근도 지원합니다. |
| **명령 팔레트** | `⌘K`로 서버와 주요 작업을 검색해 실행합니다. |
| **로컬 Mac** | 직접 배포 버전에서는 로컬 터미널과 시스템 앱 바로가기, 저장 공간 분석, 즐겨찾기·최근 파일·로그를 사용할 수 있습니다. App Store 샌드박스 버전은 로컬 터미널을 제공하지 않습니다. |
| **스토리지** | SMB·WebDAV·S3·SFTP 사이트를 등록하고 연결 테스트, 탐색, 업로드·다운로드·이름 변경·삭제를 실행합니다. 비밀번호와 비밀 키는 Keychain에 저장합니다. SMB·WebDAV는 Finder에 마운트할 수 있습니다. |
| **백그라운드 작업** | 전송·포트포워딩·압축 해제를 서버별로 확인합니다. 메뉴 막대 아이콘과 앱 안의 작업 센터에서 상태를 확인하고, 작업이 남은 상태로 종료할 때 확인합니다. |
| **테마·앱 잠금** | 밝은·어두운 테마와 Lucide 아이콘을 사용하며, Touch ID를 이용한 앱 잠금을 지원합니다. |
| **자동 업데이트** | 직접 배포 타깃은 Sparkle을 지원하며 배포 시 업데이트 피드를 설정해야 합니다. App Store 샌드박스 타깃에는 Sparkle이 없으며, 이 빌드 구성이 App Store 출시를 뜻하지는 않습니다. |

텍스트 편집은 **100KB 이하**, 이미지 미리보기는 **16MB 이하**를 지원합니다. 큰 텍스트 파일은 내려받아 열 수 있습니다. 다운로드가 끝나면 설치된 앱으로 열거나 Finder에서 확인할 수 있습니다.

앱에 저장하는 연결 비밀번호와 키 암호는 macOS **Keychain**을 사용합니다. 서버 내보내기에는 비밀번호·개인 키가 포함되지 않지만, 메모와 명령에 민감한 내용이 있을 수 있으므로 파일을 적절히 보관하세요.
