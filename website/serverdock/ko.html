02 / 매일 쓰는 도구

화면 이동은 줄이고.
하던 일에 집중하세요.

파일 편집부터 컨테이너 관리와 네트워크 점검까지. 서버 작업 공간에 담긴 다양한 도구를 살펴보세요.

핵심 작업 공간파일과 편집서버 운영명령과 자동화네트워크와 웹 도구연결·정리·보안
01

목록에서 찾아, 바로 편집

파일 목록에서 클릭해 열고, 터미널 옆에서 바로 편집하세요. 폴더 이동 명령이나 터미널 편집기 사용법을 외우지 않아도 파일을 탐색하고 수정할 수 있습니다.

02

내 방식대로 연결하는 터미널

기존 OS SSH 명령과 설정을 사용하거나 내장 libssh2 엔진을 선택하세요. 현재 작업 폴더도 함께 따라갑니다.

03

셸 너머의 원격 화면

RDP로 Windows에 연결하거나 VNC를 사용하세요. 보기, 제어, 화면 캡처와 크기 조절을 지원합니다.

04

서버 서비스를 내 포트로

로컬·원격·동적 SOCKS 터널을 관리하고, 창을 숨긴 뒤에도 백그라운드에서 유지하세요.

05

서버의 지금을 확인하세요

CPU, 메모리, 디스크, 네트워크와 지원되는 GPU 지표를 확인하세요. 로그와 리소스 경고도 놓치지 마세요.

06

키와 자격 증명은 내 손에

macOS Keychain과 1Password·Secretive 등 SSH 에이전트를 사용하세요. 실제 SSH 키 파일 관리 도구도 제공합니다.

파일과 편집

파일을 다루는 일, 외워야 할 명령은 줄이고.

07

이어가는 파일 전송

업로드·다운로드를 동시 전송 큐에서 관리하세요. 진행률을 확인하고 일시정지하거나 이어받으며 다른 작업을 계속할 수 있습니다.

08

쌓이는 로그를 실시간으로

텍스트 로그를 실시간 추적 화면으로 여세요. 필요한 문구를 필터링하고, 잠시 멈추거나 새 줄을 자동으로 따라갈 수 있습니다.

09

디스크를 차지하는 폴더 찾기

폴더별 용량과 비율을 큰 항목부터 확인하세요. 하위 폴더로 들어가 원인을 좁히고 결과에서 파일을 바로 열 수 있습니다.

10

권한이 필요한 파일도 편집

권한 때문에 열거나 저장할 수 없는 원격 파일은 지원되는 환경에서 sudo로 편집하세요. 저장할 때 기존 소유자와 권한을 유지합니다.

11

미리 보고, 풀고, 다른 앱으로

이미지를 미리 보고 서버의 도구로 지원되는 압축 파일을 풀어보세요. 다운로드한 사본은 Mac의 다른 앱으로 열거나 공유할 수 있습니다.

12

자주 쓰는 파일은 한 번에

서버별 즐겨찾기와 최근 파일에서 작업을 이어가세요. 매번 경로를 찾아가지 않아도 자주 쓰는 설정 파일과 폴더로 돌아갈 수 있습니다.

서버 운영

상태를 보고, 원인을 찾고, 다음 조치까지.

13

Docker·Podman을 화면에서

컨테이너와 이미지를 살펴보고 로그·사용량을 확인하거나 시작·중지하세요. 서버에 지원되는 엔진이 설치되어 있으면 사용할 수 있습니다.

14

systemd 서비스 관리

이름과 상태로 서비스를 찾으세요. 서버 계정의 권한 범위에서 시작·중지·재시작·설정 다시 읽기와 부팅 시 실행을 관리할 수 있습니다.

15

실행 중인 프로세스 파악

CPU·메모리 사용량으로 정렬하고 세부 정보와 실행 명령을 확인하세요. Linux·macOS와 이 Mac에서 지원되는 프로세스 제어를 사용할 수 있습니다.

16

CPU·메모리 너머의 지표

지원되는 Linux 서버에서 CPU 온도, I/O 대기, 디스크 전송 속도·IOPS와 네트워크 인터페이스별 트래픽까지 살펴보세요.

17

미리 확인하는 서버 경고

지원되는 환경에서 디스크 부족, 계정·비밀번호 만료, 재부팅 필요 여부를 확인하세요. 높은 사용량이 지속되면 리소스 알림으로 파악할 수 있습니다.

18

깨우기부터 재시작까지

MAC 주소를 저장해 Wake-on-LAN으로 서버를 깨우세요. 필요한 권한이 있는 서버는 확인 후 재부팅하거나 종료할 수 있습니다.

명령과 자동화

반복은 줄이고, 익숙한 작업 방식은 그대로.

19

변수를 넣어 재사용하는 스크립트

자주 쓰는 명령을 {{변수}}와 함께 저장하세요. 값을 입력한 뒤 선택한 터미널에 넣거나 실행할 수 있습니다.

20

여러 서버에 한 번에 실행

서버나 그룹을 선택해 명령을 실행하고 서버별 결과를 비교하세요. 실행 기록을 다시 열거나 실패한 대상만 재시도할 수 있습니다.

21

서버 맥락 안에서 받는 AI 도움

설정한 AI 서비스나 지원되는 CLI를 연결하세요. 서버별 대화 기록을 이어가고 제안된 명령을 해당 터미널로 보낼 수 있습니다.

22

tmux·zellij 세션으로 돌아가기

서버의 세션 목록을 보고 연결하거나 이름을 지정해 만드세요. 새 터미널을 열 때 tmux에 자동으로 연결하도록 설정할 수 있습니다.

23

작업 옆에서 확인하는 Git 상태

저장소의 브랜치와 변경 파일 수를 상태 표시줄에서 확인하세요. 자주 쓰는 Git 명령은 터미널 도구 모음에서 꺼내 쓸 수 있습니다.

24

옵션을 골라 만드는 명령

입력 폼으로 rsync 전송이나 chmod·chown 명령을 준비하세요. 생성된 명령을 확인하고 복사하거나 터미널에 넣어 사용할 수 있습니다.

네트워크와 웹 도구

필요한 위치에서 연결 상태를 확인하세요.

25

Mac에서도, 서버에서도 HTTP 확인

이 Mac 또는 SSH로 연결된 서버에서 GET·HEAD 요청을 보내세요. 상태 코드, 응답 시간, 리디렉션과 헤더를 확인할 수 있습니다.

26

네트워크 진단 도구 모음

Ping, DNS 조회, TCP·UDP 확인, Traceroute, Whois, 서브넷 계산과 포트 참고표를 각 도구 탭에서 사용하세요.

27

어떤 포트가 열려 있는지

TCP·UDP 리스너의 주소와 프로세스를 살펴보세요. 외부 인터페이스 바인딩인지 루프백 전용인지 확인하고 검색·필터로 좁힐 수 있습니다.

28

지원되는 방화벽 규칙 관리

Linux 서버의 ufw·firewalld 규칙을 살펴보고 관리하세요. 규칙 변경에는 서버에서 해당 작업을 할 수 있는 권한이 필요합니다.

29

인증서와 도메인 확인

TLS 인증서의 이름·발급자·만료일·지문을 확인하세요. 공개 Certificate Transparency 기록에 등록된 하위 도메인도 찾아볼 수 있습니다.

30

SSH 터널로 여는 웹 관리 화면

로컬 터널을 만들고 서버의 웹 서비스를 앱 탭에서 여세요. Grafana·Proxmox·Portainer 등의 프리셋으로 연결을 준비할 수 있습니다.

연결·정리·보안

기존 설정을 가져오고, 서버별 작업을 정리하세요.

31

SSH 서버 밖의 저장소까지

SMB·WebDAV·S3 호환 저장소·SFTP에 연결하세요. 지원되는 SMB·WebDAV 저장소는 Finder에 마운트할 수 있습니다. SMB는 샌드박스 빌드에서 제외됩니다.

32

실제 SSH 파일 관리

키를 생성·가져오기하고 SSH config의 Host 설정과 known_hosts를 관리하세요. 읽기 전용 모드로 파일 변경 없이 살펴볼 수도 있습니다.

33

Touch ID로 작업 공간 잠금

Touch ID 또는 Mac 암호로 앱 잠금을 해제하도록 설정하세요. 잠금 화면 뒤에서도 세션·전송·터널은 계속 유지할 수 있습니다.

34

점프 호스트를 거쳐 연결

ProxyJump와 지원되는 SSH 에이전트 인증으로 경유 서버를 사용하세요. OS SSH 모드에서는 기존 SSH 설정에 맞춰 연결할 수 있습니다.

35

기존 호스트 프로필 가져오기

iTerm2의 SSH 프로필을 가져오거나 ServerDock 연결 프로필을 내보내고 가져오세요. 프로필 내보내기에는 비밀번호와 개인 키가 포함되지 않습니다.

36

⌘K로 다음 작업 찾기

명령 팔레트에서 호스트·탭·스크립트·저장소와 작업을 검색하세요. 그룹·색상으로 서버를 정리하고 화면 공유 시 주소를 가릴 수 있습니다.

기능 제공 여부는 서버 OS, 설치된 도구, 계정 권한과 앱 배포 형태에 따라 다릅니다. AI 기능은 사용자가 설정한 서비스나 지원되는 CLI가 필요합니다.

알아두면 좋은 내용.

명령줄에 익숙하지 않아도 사용할 수 있나요?

파일 탐색과 편집은 화면에서 할 수 있어 터미널 편집기부터 배울 필요가 없습니다. 명령이 필요한 작업은 편집기 옆의 터미널에서 이어서 할 수 있습니다. 서버 접속 정보와 접근 권한은 필요합니다.

어떤 Mac에서 실행할 수 있나요?

macOS 14 Sonoma 이상의 Apple Silicon Mac이 필요합니다. 소스 빌드는 Xcode 16 이상과 XcodeGen을 사용합니다.

한국어를 사용할 수 있나요?

네. 기본 언어는 영어이며 Settings → General → Language에서 한국어를 선택한 뒤 다시 실행하면 됩니다. 번역이 없는 문구는 영어로 표시합니다.

기존 SSH 설정을 사용할 수 있나요?

OS SSH 모드는 로그인 셸에서 명령을 실행하고 기존 SSH 설정을 따릅니다. 통합 연결을 위한 내장 엔진도 제공합니다. App Store 샌드박스 버전은 내장 엔진을 사용합니다.

소스 코드와 라이선스는 어떻게 되나요?

GitHub에서 소스를 확인할 수 있으며 PolyForm Noncommercial 1.0.0을 적용합니다. 조건에 따라 비상업적으로 사용할 수 있으며, 상업적 사용을 허용하는 자유 라이선스는 아닙니다.

서버를 내보내면 무엇이 포함되나요?

연결 프로필, 그룹, 메모, 색상이 포함됩니다. 비밀번호와 개인 키는 제외되지만 메모와 명령에 민감한 정보가 있을 수 있으므로 파일을 안전하게 보관하세요.
