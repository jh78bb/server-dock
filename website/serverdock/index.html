A FEW USEFUL DETAILS

Before you connect.

Do I need to be comfortable with the command line?

You can browse files and edit them through the interface without learning a terminal editor first. The terminal remains available beside the editor for tasks that need commands. Server access details and permissions are still required.

What do I need to run ServerDock?

macOS 14 Sonoma or later on an Apple Silicon Mac. Source builds require Xcode 16 or later and XcodeGen.

Does it support Korean?

Yes. English is the default. Choose 한국어 in Settings → General → Language and restart the app. Untranslated text falls back to English.

Can I use my existing SSH setup?

OS SSH mode runs your command through your login shell and honors your SSH configuration. The built-in engine is available for integrated connections. App Store sandbox builds use the built-in engine.

Is ServerDock open source?

The source is available on GitHub under PolyForm Noncommercial 1.0.0. It permits noncommercial use under its terms; it is not a permissive commercial-use license.

What’s included in a server export?

Connection profiles, groups, notes, and colors. Passwords and private keys are excluded. Notes and commands can still contain sensitive information, so store exports carefully.
