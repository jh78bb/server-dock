# Changelog

All notable changes to this project are recorded here, following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
On release, `scripts/release.sh` archives the `[Unreleased]` section below into the matching version and syncs it to the GitHub Release, the in-app update dialog, and the Sparkle appcast.

## [Unreleased]
- Added **SSH Agent** authentication (Authentication Method › SSH Agent) for 1Password, Secretive and the system ssh-agent: choose the agent in the host form (detected from their default sockets) and the server login uses the keys held by the agent, so the private key never passes through the app. Works with the built-in engine (libssh2 agent) and OS SSH (`IdentityAgent`); the connection test explains common agent failures.
- Connection test: the "server closed the connection before sending its SSH banner" hint now explains the usual causes (OpenSSH 9.8+ PerSourcePenalties "Not allowed at this time", sshd MaxStartups, a temporary fail2ban/firewall ban, sshd not running — typically not a known_hosts problem) and what to try
- Added **Duplicate Host**: right-click a host in the Hosts sidebar (or use the ⋯ menu in the management window) to copy it, with its connection settings, notes, color and saved password, as "<name> copy" right below the original
- **Renamed the app from ServerDesk to ServerDock.** The app, project, targets, folders, source symbols, scripts, documentation and all translations now use the new name; the bundle ID is `com.kavaz.serverdock`. On first launch, hosts, scripts, key lists, AI history and other data in `~/Library/Application Support/serverdesk` are copied to `…/serverdock`, preferences are copied from the old `com.kavaz.serverdesk` domain, and saved keychain items (host passwords, SSH keys, storage passwords) are copied to the new `com.serverdock.*` services (macOS may ask once to allow access); the old data is left untouched. Installed ServerDesk 1.0.2 builds cannot auto-update into ServerDock because the bundle ID changed. The Mac App Store build can't read another app's container, so it starts empty
- Added five interface languages — Japanese, Simplified Chinese, Traditional Chinese, Español and Português (Brasil) — alongside English and 한국어 (about 2,000 strings each; Settings › Language, takes effect after restarting). The translations were written for this release and haven't been reviewed by native speakers, so wording corrections are welcome
- Terminal toolbar: removed the New Terminal button (the + button above the terminal does the same); the toolbar guide no longer lists it
- Terminal toolbar tooltips now use the app's own tooltip (which appears reliably after a short hover) instead of the system .help tooltip, which often didn't show on these buttons
- Fixed the installed app quitting right at launch with "Library not loaded: RoyalVNCKit.framework": RoyalVNCKit is a dynamic library, but it wasn't being embedded in the app bundle (it only worked when run from Xcode, which supplies the build folder). project.yml now embeds it in both the normal and the Mac App Store targets
- Edit AI now has a Model setting per AI: Default (the CLI picks), common models for Claude (Sonnet / Opus / Haiku aliases and full IDs) or ChatGPT (Codex), or any model ID you type. It applies to AI Chat and the AI Command Generator; the model shown in the generator is the one in use. Older saved AIs keep working unchanged
- AI Command Generator: pick the AI right in the popover from the same registered AI list as AI Chat, with Edit This AI… and Add AI… in the same menu (provider, where it runs, standing instructions — which the generator now follows); the model in use is shown and the choice is shared with that host's AI Chat
- Terminal toolbar: removed the "open this directory in the file browser" button (the right-hand file panel already follows the terminal's folder); the toolbar guide no longer lists it
- Terminal toolbar: hovering a button now shows the same explanation as the ? guide (name plus description); both use one shared text source
- Terminal toolbar guide (?) now lists only the buttons that are actually shown: no AI Chat or Port Forwarding on the local Mac, and Git only inside a Git repository
- Terminal toolbar reordered into groups: path · favorite, then Files (open folder, new file, upload) | Commands (common commands, scripts, Git) | AI (command generator, chat) | Session (tmux, port forwarding, host overview) | Terminal (clear, new terminal) | help; the ? guide follows the same order and now lists the Git button
- Terminal toolbar: the Git button is now icon-only (a long branch name no longer pushes the other buttons out); the branch, ahead/behind and change count are at the top of its menu and in its tooltip, and a yellow dot on the icon marks uncommitted changes
- Terminal toolbar: the ✨ button is now an AI Command Generator — describe what you want in plain words and the AI writes one shell command (with a one-line explanation and a safe / caution / danger rating); you can edit it, then Insert (type only), Run (risky ones ask twice) or Copy, and nothing runs by itself. Uses the same provider and location as AI Chat. Running a full CLI agent on the server is now a link inside the popover instead of its own button
- Terminal toolbar: when the terminal's current folder is a Git repository, a Git button (branch name, yellow dot when there are uncommitted changes) appears with grouped commands — status/diff, history, branches/remotes/tags/stashes, fetch/pull (--ff-only) — that run right away, and commands that change the repository (add, commit, push, stash, switch, branch switching) that are only typed at the prompt so you can edit and confirm them
- Added a toolbar to the VNC/RDP viewer: Control / View only, Send Key Combination (Ctrl-Alt-Del, Alt-Tab, Esc, Tab, Windows/Command key), Screenshot (copy or save PNG), Zoom out / Actual size / Zoom in / Fit to window (⌥+scroll pans a zoomed view), Resize Window to Remote Screen, Full Screen, and Disconnect / Reconnect
